# Solovey Contracts

Independent source authority for the existing `solovey.management/v1` semantic
and wire contract. This is a source library, not a Node agent or a product release.

This metadata-only bootstrap establishes the public repository and its original
GPLv3 license. Substantive extraction from the accepted Solovey UI R6 source will
arrive through a normal producer pull request with independent conformance CI.

Until the M1 producer → Panel → Node cutover is accepted, contract meaning is
frozen at the accepted R6 baseline. There are no independently editable schema
forks. Product publication remains owned by `MalenkiySolovey/solovey-ui`.
